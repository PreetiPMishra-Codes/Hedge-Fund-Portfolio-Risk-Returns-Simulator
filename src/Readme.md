# Hedge Fund Portfolio Risk & Returns Simulator

A Python-based simulation tool designed to analyze portfolio risk, historical variance, volatility projections, and returns for hedge fund portfolios.

## Project Structure (`src/`)

* **`main.py`**: The core execution script that orchestrates the data processing, simulation, and analysis pipeline.
* **`data_loader.py`**: Handles loading, cleaning, and preprocessing of financial market data.
* **`returns.py`**: Computes asset and portfolio return metrics.
* **`portfolio.py`**: Manages portfolio weightings and calculates aggregate portfolio-level returns and performance.
* **`historical_variance.py`**: Analyzes historical variance and risk parameters.
* **`volatility_in_ml.py`**: Implements machine learning-driven volatility calculations and projections.
